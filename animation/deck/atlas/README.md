# Archetype Atlas

An interactive page showing the 22 Archetypes with their canon relationships: Rhyme (vertical, sums to 20),
Counterpose (diagonal, sums to 19 or 21), House, Channel and Reduction. It also has the magic square
(rows are Channels, columns are Houses), with the Mind/Emotion column swap computed live, and a status-style toggle.

Published privately as an Artifact: https://claude.ai/artifact/2uyw7nyxmUYMMQ8PM6zdsB

To run it locally, copy `../archetypes-v1/cards/*.jpg` next to `index.html`.
`status_styles.py` is the code-only sketch of the four status renderings (Balanced, Too Much, Too Little, Unacknowledged).
